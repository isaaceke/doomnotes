# DOOMNOTES Part 28: Cloud Sync (Firebase Firestore, Local-First)

## Architecture

- **Local**: Isar (existing).
- **Cloud**: Firebase Firestore.
- **Pattern**:
  - Local-first UI (Isar).
  - Firestore for multi-device sync.
  - Anonymous auth for now (can upgrade to email/Google later).
  - Last-write-wins by `updated_at`. [421][422]

Firestore’s mobile SDKs cache data locally and queue writes when offline, then sync when reconnected. [414][417][418]

## Firebase Setup

1. Create a Firebase project.
2. Add Android and iOS apps (matching your bundle IDs).
3. Download:
   - `google-services.json` → `android/app/`
   - `GoogleService-Info.plist` → `ios/Runner/`
4. Initialize Firebase in `main.dart`:

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart'; // generated by FlutterFire CLI

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  // ... rest of your init ...
}
```

Use FlutterFire CLI to generate `firebase_options.dart`:

```bash
flutterfire configure
```

## Firestore Schema

Collection path:

```text
users/{userId}/notes/{noteId}
```

Each note document:

```text
{
  "user_id": "...",
  "topic": "Dance",
  "summary": "Gwara Gwara tutorial...",
  "transcript": "...",
  "video_url": "[https://tiktok.com/](https://tiktok.com/)...",
  "keywords": ["gwara", "dance"],
  "is_archived": false,
  "created_at": Timestamp,
  "updated_at": Timestamp,
  "version": 1
}
```

## Integration Points

1. In `main.dart`, after initializing Isar and prefs:

```dart
final syncService = FirebaseSyncService();
await syncService.initialize();
final bridge = NoteSyncBridgeService(syncService);
```

2. After every local note save (in your capture code):

```dart
await isarDb.writeTxn(() async {
  await isarDb.collection<Note>().put(note);
});

await bridge.onNoteSavedLocally(note);
```

3. Optionally expose a “Sync status” indicator using `Connectivity` + a simple flag in `FirebaseSyncService`.

## Conflict Rule

- If cloud `updated_at` > local `createdAt`, cloud wins.
- Else local wins.
- Version increments on each cloud update.

This is simple and sufficient for a personal notes app where the same user edits from multiple devices. [421][422]

## Do Not Break

- Offline usage: app must work with no network.
- Existing topic classification, search, and source-link behavior.
- No AI chat.
