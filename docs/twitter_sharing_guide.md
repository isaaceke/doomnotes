# DOOMNOTES - TWITTER/X SHARING GUIDE
# How to share tweets and text content to DoomNotes

---

## Sharing Tweets

### Method 1: Share Sheet (Recommended)

**On iOS:**

1. Open Twitter/X app
2. Find tweet you want to save
3. Tap **Share icon** (box with arrow pointing up)
4. Select **DoomNotes** from share sheet
5. Choose topic (auto or manual)
6. Tweet text saved to your notes!

**On Android:**

1. Open Twitter/X app
2. Find tweet you want to save
3. Tap **Share icon** (three connected dots)
4. Select **DoomNotes**
5. Choose topic
6. Done!

**What gets saved:**
- Tweet text (full transcript)
- Tweet URL (link back to original)
- Topic (auto-classified or manual)
- Timestamp

---

### Method 2: Copy Link + Paste

**If share sheet doesn't work:**

1. Copy tweet URL (long-press → Copy link)
2. Open DoomNotes
3. Tap + button
4. Paste URL
5. App fetches tweet text automatically
6. Save to topic

---

## Sharing Text from Any App

### Method 1: Share Menu

**Works from:**
- Notes apps
- Browsers (article text)
- Messaging apps
- Any app with share functionality

**Steps:**

1. Select text you want to save
2. Tap **Share** or **Copy**
3. Choose **DoomNotes**
4. Select topic
5. Saved!

---

### Method 2: Manual Entry

**For custom notes:**

1. Open DoomNotes
2. Tap + button (top right)
3. Select \"New Note\"
4. Type or paste text
5. Choose topic
6. Save

---

## Sharing Images with Text

### Method 1: Instagram Posts

**Steps:**

1. Open Instagram post
2. Tap **Share icon** (paper airplane)
3. Select **DoomNotes**
4. App saves:
   - Post caption (text)
   - Image thumbnail
   - Post URL
5. Choose topic
6. Saved!

---

### Method 2: Screenshots

**For memes, infographics, etc.:**

1. Take screenshot
2. Open DoomNotes
3. Tap + button
4. Select \"Add Image\"
5. Choose screenshot
6. Add description (optional)
7. Choose topic
8. Save

## Auto-Classification for Tweets

### How it works:

DoomNotes analyzes tweet text and auto-assigns topic based on keywords.

**Examples:**

| Tweet Content | Auto-Assigned Topic |
|---------------|---------------------|
| \"Just bought more \$SPY calls\" | Investing |
| \"New color grading tutorial is live!\" | Color Grading |
| \"Here's my video editing workflow\" | Video Editing |
| \"Bitcoin just hit 100K!\" | Cryptocurrency |
| \"My productivity setup for 2026\" | Productivity |

### Override auto-classification:

If DoomNotes picks wrong topic:
1. After sharing, you'll see topic picker
2. Select correct topic manually
3. Or create new custom topic

## Troubleshooting

### Problem: Share sheet doesn't show DoomNotes

**Solution:**

**iOS:**
1. Open share sheet
2. Scroll to bottom
3. Tap \"More\"
4. Enable DoomNotes toggle
5. Done!

**Android:**
1. Open share sheet
2. Tap three dots (⋮)
3. Select \"Edit\"
4. Add DoomNotes to favorites
5. Done!

---

### Problem: Tweet text not saved

**Possible causes:**
- Tweet was deleted
- Account is private
- Network error

**Solution:**
- Try copying text manually
- Use \"New Note\" feature
- Check internet connection

---

### Problem: Wrong topic assigned

**Solution:**
- Enable \"Always show manual topic picker\" in settings
- Or edit note after saving (tap note → edit → change topic)

## Advanced Tips

### Tip 1: Create Topic for Each Course

If you're taking online courses:
- Create topic: \"Machine Learning Course\"
- Share all related tweets to this topic
- Keep all course notes organized

### Tip 2: Use Hashtags in Descriptions

When sharing:
- Add hashtags like #investing #colorgrading
- Makes search easier later
- Helps auto-classification

### Tip 3: Batch Process Tweets

If you have many tweets to save:
1. Copy all URLs to clipboard
2. Open DoomNotes
3. Use batch import feature
4. Select topic for all
5. Done in one go!
